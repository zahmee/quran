# إعداد النسخ الاحتياطي عبر Google Drive

تعتمد شاشة النسخ الاحتياطي على Google Authorization وDrive REST API v3، وتطلب صلاحية
`drive.appdata` فقط. هذه الصلاحية تتيح للتطبيق قراءة وكتابة ملفاته داخل مجلد مخفي خاص به،
ولا تمنحه الوصول إلى بقية ملفات المستخدم.

## إعداد Google Cloud

1. أنشئ مشروعًا أو اختر مشروع التطبيق في Google Cloud Console.
2. فعّل **Google Drive API** للمشروع.
3. أكمل شاشة OAuth consent باسم التطبيق وبريد الدعم وسياسة الخصوصية.
4. إذا كانت شاشة OAuth في وضع الاختبار، أضف حسابات Google التي ستجرب التطبيق ضمن Test users.
5. أنشئ OAuth Client من نوع **Android** بالقيم التالية:
   - Package name: `com.mushaf.reader`
   - SHA-1: بصمة مفتاح التوقيع المستخدم لبناء التطبيق.
6. أنشئ Android OAuth Client إضافيًا لكل بصمة مختلفة:
   - مفتاح debug أثناء التطوير.
   - مفتاح release المحلي.
   - مفتاح Google Play App Signing عند النشر في المتجر.

لعرض بصمات البناء المحلي:

```powershell
.\gradlew.bat signingReport
```

لا يحتاج هذا التكامل إلى `client_secret` داخل التطبيق، ولا ينبغي وضع أي أسرار في المستودع.

## تحقق عملي

1. ثبّت بناءً موقّعًا ببصمة مسجلة في Google Cloud.
2. افتح: الإعدادات ← التطبيق ← النسخ الاحتياطي.
3. اربط حساب Google ووافق على الوصول إلى بيانات التطبيق في Drive.
4. أنشئ نسخة وتأكد من ظهور تاريخها وحجمها واسم الجهاز.
5. على جهاز آخر يحمل نسخة موقعة مسجلة، اربط الحساب نفسه ثم نفّذ الاستعادة.

إذا ظهر خطأ صلاحية، فتحقق أولًا من تفعيل Drive API ومن تطابق اسم الحزمة وبصمة SHA-1.
