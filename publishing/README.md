# مواد النشر

يجمع هذا المجلد أصول Google Play ولقطات الشاشة ونص صفحة المتجر.

## الملفات

- `play-store-icon-512.png`: أيقونة المتجر 512×512.
- `feature-graphic-1024x500.png`: الصورة المميزة 1024×500.
- `screenshots/`: لقطات هاتف توضيحية.
- `store-listing-ar.md`: نص المتجر العربي.
- `privacy-policy.html`: نسخة أرشيفية من سياسة الخصوصية؛ النسخة المنشورة موجودة في `docs/`.

## قائمة تحقق قبل النشر

1. حدّث لقطات الشاشة إذا تغيرت الواجهة تغييرًا جوهريًا.
2. تأكد من تطابق الوصف مع النسخة المبنية ومع متطلبات Google Play الحالية.
3. ابنِ AAB موقّعًا من بيئة آمنة، ولا ترفع مفتاح التوقيع أو كلمات مروره.
4. راجع سياسة الخصوصية وحقوق محتوى المصحف قبل التوزيع.

> ملفات `*.apk` و`*.aab` مستبعدة عمدًا من المستودع. استخدم GitHub Releases للتوزيع العام.
